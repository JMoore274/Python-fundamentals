# Python Fundamentals

Practice functions I wrote while completing **Foundations of Programming (Python)** at Western Governors University, as part of my B.S. in IT Management.

## Skills Demonstrated
- String manipulation, cleaning, and slicing
- Lists and dictionaries
- Loops, conditionals, and functions
- Common patterns: counting, filtering, accumulating, best-so-far

## Project Structure
| Folder | Files | What it covers |
|---|---|---|
| `strings/` | count_vowels, remove_spaces, clean_username, get_first_4_chars | Text processing and input cleanup |
| `lists_dicts/` | average_price, get_positive_numbers, create_employee_ages | Working with collections of data |
| `loops/` | count_high_scores, find_biggest, times_table | Counting, searching, and generating values |

## How to Run
Each file includes test lines at the bottom. Run any file with:
```
python strings/count_vowels.py
```
